# QuotaPulse v1.0.14 Release Notes

Release date: 2026-09-07

## Highlights

- Renamed the GitHub repository to `QuotaPulse` and aligned README, release,
  update-check, Sparkle, and pricing-catalog links with the new name.
- Added a compatibility Sparkle feed at the pre-rename URL so existing
  installations can continue discovering updates.
- Updated the release workflow to keep the compatibility feed synchronized.
- Updated the Codex API-equivalent value catalog and runtime refresh path.

## Compatibility and privacy notes

- Xcode project and scheme names, bundle identifiers, App Group, and Keychain
  identity remain unchanged to preserve existing local data and credentials.
- The release is signed with the project's stable Apple Development identity
  and is not Developer ID notarized. Another Mac may require approval in
  System Settings > Privacy & Security before first launch.
